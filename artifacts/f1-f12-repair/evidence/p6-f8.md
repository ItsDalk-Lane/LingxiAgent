## 实现

### shared/reserved-tag-stream.ts（三概念分离重写）

1. **已知协议块**：词表匹配优先级不变，结构化 open/close 语义照旧（含不透明内容、跨 delta 挂起）。
2. **正常未知标记开启栈**（新，`unknownStack`）：`matchGenericTag` 按标准文本标记语法匹配
   - 开标签（含属性；引号内 `>` 不是终止符）、闭标签、自闭合 `/>`；
   - `<!--…-->` 注释、`<![CDATA[…]]>`、`<?…?>`/`<!…>` 声明原样保留且不入栈；
   - 名字字符集沿用原 CLOSE_TAG_SHAPE（含 `mm:think` 命名空间方言），大小写敏感；
   - 配对闭标签原样保留并弹出对应开启记录；**真正无开启记录的未知闭标签才在
     `dropUnknownOrphanClosers`（最终边界）清理**；
   - 错配嵌套按保守透传（弹出匹配项，不删正文）。
3. **转义/代码保护**：转义升级为形状无关（`\` + 任意完整标记形状，含未知名字与注释/CDATA），
   **反斜杠在链上保留**——受保护字面量不被任何层吞掉或再解释；新增共享纯函数
   `stripTagEscapes`（与 matchGenericTag 同源判定，引号属性内的 `>` 不误判，幂等）。
4. **有界解析保护（P6.4）**：未知栈深度上限 128（达到→本段保守透传并停止激进清理）；
   挂起半截标记上限 16KB（超过→按字面吐出，不无限缓冲）。flush 仍按字面定界。

### 显示层一次性消费（P6.3）

- `StreamingMarkdownContent`（live 与历史正文共用渲染收口）：`source` 先过 `stripTagEscapes`
  再渲染——转义反斜杠只在此处消费一次，等价且幂等；canonical/落盘文本保留 `\`，
  历史重渲染不再二次解释（T14 稳定）。

### core/events.ts

- 契约注释更新（转义链上保留、显示层消费）；MoodParser=链尾（孤儿清理开启）、
  ThinkTagParser=中间层（关闭）分层不变——但现在中间层的未知栈会记录 `<mood>` 等下游
  结构标签的开启，`</mood>` 在中间层是「有开启记录的闭标签」按保留透传，不再依赖
  「中间层恰好不删」的巧合。

### desktop history-segment-sanitizer.ts（T16）

- 无 leading block 可剥离时不再 `return source`：按切分结果重建（受保护字面量原样），
  扫描器已吞的孤儿残渣不被还原；已净化文本重建与原文一致时仍返回原对象（幂等）。

### 有意未改（核查结论）

- `core/llm-client.ts` stripTaggedThinking、`core/message-utils.ts` stripThinkTags、
  `core/session-coordinator.ts` extractPlainTextFromContent：均只剥**成对**已知 think 标签
  （非显示正文的派生用途），不删任何孤儿/未知闭标签，不在本缺陷范围。
- splitReservedTagSegments 四个调用方（message-parser/format/assistant-block-builder/
  history-sanitizer）都是最终文本边界，孤儿清理默认开启符合 P6.3 边界语义。

## 限制（P6.4 如实声明）

- 本方案只能判断「是否存在对应开启标记」，不能凭字符形状可靠识别所有未知成对思考内容：
  若某新方言的**成对**标签恰好是我们不认识的普通形状，按「正常未知标记」原样保留
  （不隐藏正文）——这是保守方向的取舍，不宣称永不泄漏任何新方言。
- 超深嵌套/超长未结束标记在上限后转入保守透传（正文不丢，但该段不再做孤儿清理）。
- 不批量改写历史 JSONL：历史残渣只在既有渲染适配边界清理显示，过去已物理丢失的
  字符不能推断恢复。

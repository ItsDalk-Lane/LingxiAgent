## 实现

### 服务端（core/speech-recognition-service.ts）
- `_resolveTranscriptionTarget`：严格解析失败且 provider `authType === "none"` 时回落 `includeCatalog: true`（系统身份目录直通）；api-key 云端候选保持不可执行。
- 两处失败记录（独立转写 + 语音附件转写）：`err.code` 存在时以 `CODE: message` 前缀写入 `transcription.error`，沿 route → 前端同链透出。

### 前端
- `desktop/src/react/utils/system-dictation.ts`（新增）：
  - `probeSystemDictationBackend`：GET `/api/media/providers?capability=speech_recognition`，`system-speech` 的 models/catalogModels 含 `system-speech` 即后端可用（listProviders 只保留 adapterAvailable 项，出现即代表适配器已注册）。Mac 浏览器连非 Mac 后端/移动 WebView/缺宿主桥 → 明确不可用。
  - `unwrapDictateTranscription`：按形状解包 `{ok, transcription}`——`typeof transcription === 'string'` 仅显式旧版分支；对象读 `status/text/error`；ready 空文本 → empty；外层 ok 不覆盖内层 failed。禁止 `String(object)`。
  - `describeDictateFailure`：`SYSTEM_SPEECH_*` 码 → 区分文案键（未授权/被拒绝/受限/helper 缺失/识别不可用/超时/取消）；未知消息原样透出（HTTP 层服务端错误不吞成「录音失败」）。
- `ComposerToolbar.tsx`：真实语音入口（此前完全无按钮）：`voice-toggle`（录音/停止态切换，busy 禁用）+ `dictate-toggle`（aria-pressed，仅后端可用时渲染）；`VoiceControls` 接口。
- `InputArea.tsx`：
  - P5.1 选择器：`canSendNativeAudio`（模型原生音频）与 `canUseSystemDictation`（surface=desktop + `window.hana.speechPermissionStatus` 桥 + 后端探测，重连重探）。删除死的 `isMacDictateAvailable`（navigator.platform 判断）。
  - P5.2：`modeAtStart` 快照（`audioRecordingModeRef`，启动时落定、停止结算与自动丢弃都读它）；生命周期扩为 `idle/requesting_permission/starting/recording/stopping/transcribing/error`（在途不可重复开始，error 可重试）；自动丢弃效应只对 `mode === 'native-audio'` 且模型失去原生音频能力生效——听写不再因文本模型被丢弃；快捷键与按钮同一能力门禁（`canSendNativeAudio || canUseSystemDictation`）。
  - P5.3：转写解包按 `unwrapDictateTranscription`；`lingxiFetch` 传 `throwOnHttpError:false + signal`（旧实现默认抛 HTTP 错导致 ok 检查永不可达）。
  - P5.4：保真插入 `buildFaithfulPasteContent(text)`（纯 text 节点 + hardBreak，`<tag>`/空格/换行不进 HTML 解释——复用 P7 原语）；每次转写铸 `DictateOperation{id, sessionPath, sessionId, connectionWs, abort}`，插入前校验 op 未被取代、会话未切、WebSocket 实例（连接代次）未变；卸毁 abort + 失效；停录即 `disposeAudioRecorderRuntime`（麦克风/AudioContext/processor 释放，等识别不占设备）；AbortError 静默收尾（用户取消非失败）。
  - 录音卡：不再要求 showAudioInput 才显示；标题区分授权中/转写中/失败态；`data-testid="audio-recording-card"`。
- locale：5 文件各 +12 键（voiceInput、audioRecordingFailedTitle、dictateRequestingPermission/Transcribing/PermissionRequired/PermissionDenied/PermissionRestricted/HelperMissing/RecognizerUnavailable/Timeout/Cancelled/Failed），复用既有 dictateOn/dictateOff/dictateEmpty/dictateSpeechPermissionBlocked。
- Swift `SpeechTranscriber.swift`（P5.4）：`requiresOnDeviceRecognition` 由「支持才开」改为**始终要求**；`supportsOnDeviceRecognition == false` → 显式 `recognizerUnavailable`（识别不可用文案），不静默改用 Apple 云端识别。授权检查仍在前（先权限后能力）。

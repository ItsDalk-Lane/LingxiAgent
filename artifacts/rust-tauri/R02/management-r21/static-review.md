# 同根因静态复核（非运行验收）

| 根因 | 全部共用入口 | 本轮处理与静态结论 | 剩余条件 |
|---|---|---|---|
| 审计日志路径故障晚于业务提交才发现 | 管理写入 `change`（网络、资料、密码、Web 登录/会话）；密码旧格式升级、Web 注销；认证双注册簿 `persist`（签发、设备/凭证撤销、配对创建/到期/批准） | 即使旧审计为空也打开并检查日志；各写路径在业务持久化前检查旧审计并补投影。目录占位、链接、坏行、超限会先返回错误。设备签发测试验证拒绝后双注册簿不变；独立第 59 例已定义，尚未真 TCP 执行。 | 提交后突发磁盘故障仍由持久 outbox 延后投影。旧 Node 标准日志也是 best-effort；R00 未要求 JSONL 与业务记录跨文件同步原子，但正式叶需独立故障恢复证据。 |
| 文件路径链接与无界审计扫描 | `security_audit::project`，启动补投影及所有管理/认证写 | Unix 用固定 home/logs 描述符与 `mkdirat/openat`、`O_NOFOLLOW`、文件属主/类型/链接数检查；日志 64 MiB、单行 64 KiB、意图 10 万上限；流式写入。链接、坏行、超限、重放/秘密缺席单测 PASS。 | Windows 分支仍为路径检查后打开，父目录替换竞态未消除；需 Windows handle-relative 安全打开与真机故障测试。达到容量上限会明确失败，尚无轮转。 |
| Windows 无真实 LAN 网卡枚举 | summary、network、二维码地址共享 `lan_ipv4_addresses` | 统一 `if-addrs`，枚举所有运行中的 IPv4 网卡，过滤回环、未指定、链路本地、组播和广播，排序去重；不依赖默认路由。多网卡与过滤单测 PASS。无可用地址时二维码明确 400。 | macOS 只跑纯过滤测试，Windows/Linux 实机与多网卡环境仍未验证。 |

本轮不触碰 A15；没有运行任何受平台当前 TCP `EPERM` 阻止的等效网络探针。阶段 PASS/R03 仍由完整门禁和独立验收决定。

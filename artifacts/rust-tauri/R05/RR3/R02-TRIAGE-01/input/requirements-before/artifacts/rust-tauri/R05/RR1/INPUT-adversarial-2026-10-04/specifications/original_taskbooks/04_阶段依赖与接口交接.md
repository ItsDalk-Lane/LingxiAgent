# 阶段依赖与接口交接

## 1. 默认顺序

```text
R00 基线与范围
 → R01 契约与高风险原型
 → R02 独立服务/认证/存储/事件
 → R03 运行状态机/取消/恢复
 → R04 统一工具网关/文件/进程/MCP
 → R05 模型/凭证/流式/完整闭环
 → R06 上下文/历史/记忆/知识
 → R07 外围能力/后台/各入口
 → R08 旧Electron界面＋Rust/数据迁移演练
 → R09 Tauri正式宿主
 → R10 对抗性全验收/性能/四平台产物
 → R11 旧路径清退/最终产物/授权发布
```

R01提前验证浏览器/PDF/权限替代风险，R07/R09才完成生产实现。R03使用外部替身验证真实内核，R05才形成真正模型协议→真实工具→历史的完整闭环。因此不能把R02健康检查成功或R03替身任务完成当作Rust内核全部迁移。

R08和R09故意分开：先证明换内核，再证明换宿主，避免五种变化同时发生后无法定位。

## 2. 交接物

| 阶段 | 必须交给后续的确定输入 | 消费阶段 |
|---|---|---|
| R00 | F-ID/入口/存储/Pi清单、夹具、阈值、基线失败 | 全部 |
| R01 | 所有权、协议/版本、依赖锁、宿主ADR、迁移/回滚规则 | R02—R11 |
| R02 | service/认证上下文、Storage/Event/Clock ports、实例与单写者 | R03—R08 |
| R03 | Run/Attempt/取消/恢复、工具/模型ports、统一任务提交 | R04/R05/R07 |
| R04 | Registry/Gateway、批准、Resource/Process、MCP/worker协议 | R05—R09 |
| R05 | ModelGateway、Credential、流规范化、完整闭环、trace/usage | R06—R09 |
| R06 | Session/Context/Memory/Skill/Knowledge及统一历史 | R07—R09 |
| R07 | 全业务API与外围执行器、worker账本、真实账户缺口 | R08—R10 |
| R08 | 通过的Electron-Rust对照、ServiceClient/DesktopHost、迁移/回滚 | R09—R11 |
| R09 | Tauri候选、宿主矩阵、四平台原生结果、产物配置 | R10/R11 |
| R10 | 完整验收/性能/安装证据与独立审查 | R11 |
| R11 | 最终源树/产物hash、用户文档、终验与发布状态 | 用户/维护者 |

每次交接包含：`source_sha / working_tree_digest / protocol_version / data_epoch / dependency_locks / accepted_tasks / unresolved_items / allowed_next_scope / artifact_hashes`。不存在的接口应明确标未实现，不把拟用名称当实际API。

## 3. 允许延后但不能被掩盖的验证

R01：实施平台宿主原型必须真实验证；其他平台未验证项可交接，但必须在R09/R10真实完成。关键能力连实施平台都没有可行路径时，替壳路线BLOCKED，不假装有通用解决方案。

R05：协议替身和真实文件闭环必须本阶段完成。无真实provider凭证可以继续不依赖该凭证的实现任务，但LIVE项仍BLOCKED，R10不得放行。

R07：每个功能真实内部接线必须完成；某平台真实账号验证可延后R10。未实现后端不属于“等待UI”的合理例外。

R09：四组平台原则上在本阶段完成原生回归；缺机器可先形成待审阅成果，R10全产品验收前必须消除，不把缺机器改写成平台不支持。

R10/R11：缺正式签名或发布授权不等于技术功能失败，分别记录。没有真实安装、必要平台或数据回滚证据则技术本身不通过。

## 4. 阶段内控制

一个阶段内每个任务都有独立交付与场景。R07范围较大，按能力域T01—T12顺序批次推进，每批给出真实闭环；不要求一次模型上下文完成全部，但阶段整体不能在剩余域未完成时通过。

上下文不足时写HANDOFF并继续同阶段，不擅自跳到后续。缺失可由源码确定的信息先读源码；无关细节由ADR作有依据的最小决定，不反复向非程序员追问实现细节。

## 5. 接口变化规则

已交接接口要修改时：列出消费者→更新单一协议源→生成TS/schema→更新兼容适配→跨语言round-trip→所有受影响入口回归→更新版本与交接。禁止只修改Rust字段让前端靠undefined兜底。

涉及权限、外部副作用、数据格式、升级降级和生命周期的改变必须附失败窗口分析。不要因为某条路径方便而允许绕过统一网关。

## 4. 逐项执行规格

### R06-T01｜上下文编译器与短提示词

**做什么：**发给模型的文本与观测详情来自同一份构建结果。

**怎么做：**

1. 从core/agent.ts及现役prompt测试提取系统约束、人格、工具目录、记忆、技能、资源、会话历史等实际组成，保留顺序与作用域。
2. 建立ContextArtifact：每段有来源、可见范围、优先级、token预算与脱敏标记；最终请求直接由artifact渲染。
3. 静态提示前缀稳定，动态内容与工具目录按原规则载入；不可把全部工具说明重新塞回常驻提示词。
4. 保留中英文及现役语言策略，子代理上下文按权限裁剪；源材料里的指令不提升为系统指令。
5. 冻结迁移前后模板差异，只允许修复契约所必需的改动，并纳入行为评测。

**必须交付：**ContextCompiler；ContextArtifact；提示词差异报告。

**验收：**

#### R06-A01｜观测和实际请求同源

前置：构建含人格/记忆/技能/工具目录的任务。

操作：比较发给模型的内容与观测展开。

通过条件：除明示脱敏外一致，无另一套重建prompt。

证据：请求和artifact摘要。

环境：本机隔离环境；外部协议使用确定性替身。

#### R06-A02｜提示词长度不暗增

前置：相同Agent配置和工具集。

操作：测量新旧静态提示及总上下文。

通过条件：不超过冻结预算；新增冗余段使测试失败。

证据：token与段来源对照。

环境：本机隔离环境；外部协议使用确定性替身。

**禁止替代：**不得以占位实现、跳过断言或仅更新完成状态替代真实实现。

### R06-T02｜token预算、压缩与长会话

**做什么：**压缩不破坏工具协议和当前任务目标。

**怎么做：**

1. 迁移现役compaction触发、手动压缩、摘要上下文、缓存保留与错误恢复语义；不要仅按字符数切断聊天。
2. 预算为系统约束/当前请求/工具定义/历史/引用/输出留空间；用模型实际tokenizer或明确保守估算并标来源。
3. 工具调用与结果成对保留，待完成调用、批准和当前目标不被压掉；压缩摘要不是可信新系统指令。
4. 压缩本身使用ModelGateway，失败保留原上下文并返回可诊断策略，不能截断重要内容继续宣称成功。

**必须交付：**ContextBudgeter；CompactionService；长会话夹具。

**验收：**

#### R06-A03｜工具对在压缩后完整

前置：长历史尾部含未闭合工具调用。

操作：触发自动压缩。

通过条件：不留下孤立tool result或丢失待完成调用。

证据：压缩前后协议断言。

环境：本机隔离环境；外部协议使用确定性替身。

#### R06-A04｜摘要失败不破坏会话

前置：摘要provider返回错误。

操作：触发压缩并重开历史。

通过条件：原始记录保留，错误明确，不把空摘要覆盖历史。

证据：数据库与上下文对照。

环境：本机隔离环境；外部协议使用确定性替身。

**禁止替代：**不得以占位实现、跳过断言或仅更新完成状态替代真实实现。

### R06-T03｜会话树、重试、fork与回退

**做什么：**保留现役可见功能而非只保留消息列表。

**怎么做：**

1. 按R00叶子功能迁移创建/列表/搜索/置顶/归档/恢复/删除/fork/重试/编辑/rewind等实际入口。
2. 保持session/parent/branch和message稳定ID；fork共享历史来源但新写入独立，权限和附件授权不能跨分支扩大。
3. 重试区分新的用户Run与同Run内部attempt；沿用现役产品语义，不覆盖已审计的旧结果。
4. 回退检查checkpoint及真实文件版本，冲突拒绝；外部消息/网络副作用不可假装回滚。

**必须交付：**SessionService；树/分支索引；回退检查。

**验收：**

#### R06-A05｜fork不串写

前置：会话A在中段fork为B。

操作：在两分支各自追加内容。

通过条件：共同历史可读，新消息独立，资源权限正确。

证据：树与消息查询。

环境：本机隔离环境；外部协议使用确定性替身。

#### R06-A06｜rewind不覆盖外部修改

前置：checkpoint之后用户手动改文件。

操作：执行回退。

通过条件：检测冲突并保护用户修改；不能伪称全部撤销。

证据：文件与回退收据。

环境：本机隔离环境；外部协议使用确定性替身。

**禁止替代：**不得以占位实现、跳过断言或仅更新完成状态替代真实实现。

### R06-T04｜统一消息历史、重连与导出

**做什么：**同一任务在不同读取方式下显示同样语义。

**怎么做：**

1. 将规范化文本阶段、MOOD、工具、附件、失败及终态存为权威消息结构；旧记录由单一LegacyImporter/Reader规范化。
2. 实时/历史分页/重连/导出/不同客户端共享语义投影，前端不独立解析模型结束或补造最终答案。
3. 保留已有streamId/seq/窗口读取的行为目标；长会话分页从索引/游标定位，不每页完整扫描全部历史。
4. 未知旧字段保留在受控legacy扩展或原始档案，无法确定的Run关联标unknown而不按时间猜。
5. 工具卡展开状态依据稳定ID维护；仅工具执行无最终回复的任务也可展开查看。

**必须交付：**CanonicalMessageStore；统一历史投影；分页/导出接口。

**验收：**

#### R06-A07｜实时与重开语义一致

操作：对比实时、重开、重连、导出。

通过条件：阶段及顺序相同，正文不混入独立思考/MOOD。

证据：规范化序列diff及UI断言。

环境：本机隔离环境；外部协议使用确定性替身。

通过条件：消息不丢重，读取字节/查询量符合索引设计。

环境：本机隔离环境；外部协议使用确定性替身。

### R06-T05｜会话文件、资源与产物身份

**做什么：**迁移后文件链接仍可用且不能越权读取。

**怎么做：**

1. 迁移SessionFile/Resource登记、附件stage/materialize、预览、缓存清理和引用授权的现役行为。
2. 旧sf_等身份尽量保留，路径变化通过显式映射；不把未授权绝对路径直接发给远端客户端。
3. 文件存在性、摘要、MIME、尺寸、所属会话/agent、授权生命周期与消息引用一致。
4. 缓存回收与权威附件分开，引用仍有效的产物不可被闲时清理误删；删除会话按原保护规则处理。

**必须交付：**ResourceService；SessionFile迁移适配；文件引用检查器。

**验收：**

#### R06-A09｜旧附件迁移后可读

前置：旧消息引用sf_与原始附件。

操作：导入并通过各客户端读取。

通过条件：身份/文件对应正确，无断链；未授权客户端拒绝。

证据：引用完整性和权限断言。

环境：本机隔离环境；外部协议使用确定性替身。

#### R06-A10｜缓存回收不误删交付

前置：附件已交付并被历史引用。

操作：运行缓存清理。

通过条件：权威文件仍可用，临时副本按策略清理。

证据：文件清单与引用检查。

环境：本机隔离环境；外部协议使用确定性替身。

**禁止替代：**不得以占位实现、跳过断言或仅更新完成状态替代真实实现。

### R06-T06｜人格、记忆与技能系统

**做什么：**保留当前能力与审核边界，不让扩展接管内核。

**怎么做：**

1. 迁移现役记忆事实/摘要/信条/梦境等实际流程的数据访问与调度调用；业务状态和模型调用由Rust负责。
2. 按Agent隔离记忆查询与写入；现役知识内容/外装技能材料均按来源和权限进入上下文。
3. 迁移Skills发现、安装/审核、启停、同步、技能包和人格文件加载，保留白名单、工作区边界与用户覆盖顺序。
4. Pi extensions实际使用的hooks逐项迁入Rust扩展ports或受控worker；不能让扩展重新调用旧Agent loop。
5. 安全检查不是保证技能无恶意；执行脚本仍受R04授权和沙盒。

**必须交付：**MemoryService；SkillService；PI_REPLACEMENT_MATRIX更新。

**验收：**

### R06-T08｜工具行为评测与上下文交接

**怎么做：**

3. 确定性契约要求100%通过；真实模型评测多次采样并报告波动，不承诺模型永不犯错。
4. 若正确性下降，先定位prompt/schema/上下文装配差异，只修实际原因；不通过无限增加系统提示补丁掩盖。
5. 交接全部Pi行为替换账本，未退出的核心依赖明确归属R07/R08或阻塞项。

**必须交付：**R06_REPORT.md；R06_HANDOFF.json；BEHAVIOR_EVAL.json。

## 5. 本阶段验证方式

逐场景执行并登记命令/预期/实际/退出码/SHA/环境/日志；相关基线回归和平台要求按[05验收协议](05_验收与性能协议.md)运行。新工具或脚本未创建前不能写成已经运行成功。

各任务的场景是最小基础：从R00功能/入口/存储清单展开适用组合，特别是身份、权限、副作用与数据迁移；不能用两个样例推定全部入口安全。外部服务替身与真正内核组件的边界必须写清。

## 6. 阶段放行条件

全部现役会话/上下文/记忆/知识叶子功能映射到真实实现；实时历史导出一致；工具/压缩协议契约通过。真实模型评测未完成的项目标明发布阻塞。

未满足必需项则标FAIL/BLOCKED；完成实现但尚未独立复核标READY_FOR_REVIEW。不得仅统计绿色测试数量。发布授权条件项独立处理，未授权不伪造其结果。

## 7. 失败与回退

保留旧数据只读来源及新库副本；恢复测试副本到阶段前快照，不覆盖真实记忆或用户资料。

回退范围只能包括本次获准修改；保留原始失败证据和用户已有数据。关键问题按根因修复同类路径并重跑受影响整组，不能另建绕过分支。

## 叶子功能登记字段

每项登记：`feature_id / parent_domain / title / classification / current_entrypoints / current_owners / current_stores / user_action / visible_result / target_owner / stage_id / task_ids / acceptance_ids / platform_scope / source_ref / status / evidence`。

对于当前未展开的功能细节，R00从注册表和真实调用链补全，而不是把“待确认”变成范围外。例如会话管理不是一个API，模型配置也不是一个按钮。发现新增叶子必须追加机器可读矩阵和测试，不需要新增产品功能。

## 硬排除与保护

已撤回：专用子代理目录/强制分发重构、独立知识研究、本地模型管理。兼容旧research数据只读/迁移不等于恢复研究运行入口。Ollama接入、现役subagent与实验开关保留。外装MCP不算内置清点，但扩展协议/权限边界属于本轮。不能依据过时个人记忆覆盖当前源码和明确排除项。[S16]

## 外围worker最终登记

字段：`worker_id / language / role / executable / allowed_operations / resource_scopes / credential_delivery / network_policy / cancellation / restart_budget / output_validation / owner / evidence`。

必须能说明没有：Agent loop、上下文构建权、批准决定权、任务终态权、跨会话消息写入权、全局provider凭证读取权。需要模型操作时通过受控Rust回调，并受同一预算与授权。开发/测试使用Node与生产内核依赖Node是两回事。

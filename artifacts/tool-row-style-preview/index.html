③ 有意不以工具行出现的调用 不是漏掉，是换了形态

调用在界面上的形态
subagent（派出子代理）不显示工具行；子代理的对话以独立代理消息块出现在会话里
media_generate-image / media_generate-video不显示工具行；成品直接以图片/视频卡片出现在消息里
show_card / hana_card_guide渲染为消息里的卡片
install_skill / update_settings / workflow / stage_files有专属卡片或静默完成，不占工具行
browser（动作=screenshot）截图直接进消息，不显示行

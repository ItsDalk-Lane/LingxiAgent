效果稿 · Skills 界面的外部 Agent 工具技能
两级启用模型：① 项目级（设置 → 技能 → 兼容技能，决定这个外部技能是否进入本项目/Skills 界面）→ ② 助手级（Skills 界面的每个助手页里逐个启停，决定哪个助手真正能用）。
1 设置·兼容技能里启用 = 对整个项目启用（可见性闸门） → 2 Skills 界面·助手页里启用 = 该助手可用 · 未在第①步启用的外部技能：Skills 界面完全不出现
① 设置 · 技能 · 兼容技能（项目级启用）
每个外部 Agent 分组里的开关 = 对整个项目启用
这一步只决定「进入不进入项目」。启用后技能才会出现在 Skills 界面；未启用的不出现。开关不再是「对某个助手启用」。

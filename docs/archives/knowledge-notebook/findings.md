## 权威需求

- 用户附件共 3911 行，是本目标的产品与架构规格。
- Notebook 是用户定义的知识域，可为空或包含多个来源；查询必须选至少一个 Notebook，可多选，不能在查询时细选文件。
- 每次发送先冻结不可变范围快照，后续 Notebook 变更不影响正在运行的回答或研究。
- 原始内容快照与解析产物必须分离；解析器升级不能制造假的内容版本。
- 快速回答只承诺检索相关内容；全文研究必须以覆盖清单证明所有分析单位和完整矛盾检查均完成。

- 来源文本是不可信数据；分析模型无工具、技能、终端、浏览器、人格或长期记忆能力。

## 引用级解析技术事实

- 仓库已经直接依赖 `unpdf` 1.6.2，且 Office 插件的 `plugins/office/lib/read-pdf.ts` 已用它按页读取 PDF 文本。无需为 PDF 页级定位新增解析依赖。
- `unpdf` 还能返回每页结构化文本项，包括文字、坐标、宽高、字号、字体、方向和换行标记；这足以建立“页码 + 规范化页内字符范围 + 文本校验和”的首版稳定 Anchor，并支持后续坐标高亮。
- AnyDoc 的类型层能为非 PDF 产生结构化块、表格、列表、标题锚点等语义结构，但其说明明确表示 PDF 只支持 Markdown，不能转结构化 Document；PDF citation 需要独立的 `unpdf` 定位分支。
- AnyDoc 的结构化块本身没有原始页码、段落号或单元格坐标来源字段；它能帮助语义拆块，但不能据此声称 DOCX/PPTX/XLSX 已达到 citation-grade。首版应严格限制完整支持格式，不把 AnyDoc 全格式能力冒充引用能力。
- 隔离工作区尚无 `node_modules`；主工作区有现成依赖可供只读源码核对。正式测试必须在隔离工作区按锁文件安装，避免把主工作区依赖状态当作干净基线。

### PDF Spike（2026-08-25，真实仓库样例）

- 对 `tests/fixtures/document-extract/sample-text.pdf` 调用 `unpdf`：得到 1 页、2 个有序文本项；两项均带页内坐标、宽高、字号和换行标记，文字分别为样例中的两行。
- 对 `sample-scanned.pdf` 调用同一路径：得到 1 页、0 个文本项，可用确定性条件标记 `needs_ocr`，无需依赖不稳定错误文案。
- 结论：PDF citation-grade 首版技术风险已关闭到“可实现”。Anchor 可冻结页码、页内规范化字符范围、原始项范围、坐标框与文本校验和；扫描 PDF 必须在解析状态中明确阻止查询。

### AnyDoc 结构忠实度 Spike（2026-08-25，真实仓库样例）

- `sample.docx` 可得到标题、段落、行内样式和二维表格结构；`sample.xlsx` 可得到二维表格结构，证明它适合生成语义块。
- 两个结构结果都没有原始 DOCX 段落编号、XLSX 工作表名/单元格地址或其它稳定来源定位；表格网格只是在解析结果内的顺序坐标。
- 结论：首版可以把这类格式作为“解析预览/未来适配”能力，但不能纳入附件要求的 citation-grade 完整来源。要升级支持，必须补各格式的原始定位适配和重启后跳转测试。

## 安全约束

- SQL 只允许参数化语句；标识符和枚举值走白名单。
- 文件导入校验真实路径、软链接、敏感路径、大小、类型和扩展，并复制到托管的不可变存储。
- 网页导入若进入首版，必须阻断本机/内网目标并对每次跳转重新校验；否则明确不支持，不做静默抓取。
- API 输入需要运行时结构校验、范围归属校验与成本控制；错误响应不泄露路径、正文、凭证或堆栈。

## FTS Quick Answer 已核对事实

- 范围快照的最小不可变身份是 Notebook 名称、来源、内容快照和可引用解析产物；同一逻辑来源出现在多个 Notebook 时范围保留成员关系，执行检索按解析产物去重。
- 中文全文索引必须保存正规化原文、分词结果和 2/3 字符 n-gram；查询只拼接经过双引号转义的字面量，不能接受外部全文检索语法。
- Chunk 只属于可重建缓存。它的每个字符范围都映射回事实库中的 Block；引用提交前把 Chunk 偏移转换为 Block 偏移并逐字复验。
- 标准回答的模型不能直接产出可信引用编号。它只能返回候选编号、原句和范围，服务端验证后才创建引用事实；连续两次结构或引文无效时整份回答失败。
- 历史引用查看必须调用引用解析接口，不能依赖当前 Notebook 的来源列表；因此来源被移除后仍可从冻结快照打开并高亮。

## Provider Operation 与混合检索已核对事实

## 全文研究与证据链已核对事实

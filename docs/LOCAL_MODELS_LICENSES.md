# 本地模型许可证说明

Lingxi 本体采用 Apache-2.0。模型权重和推理运行时是独立分发物，不因被 Lingxi 下载或调用而自动变成 Apache-2.0。

| 稳定模型 ID | 目录标注 | 当前兼容性结论 |
|---|---|---|
| `qwen3-embedding-0.6b` | Apache-2.0 | 目录层面可兼容；仍以实际资产包内许可证为准 |
| `sensevoice-small` | Apache-2.0 | 目录层面可兼容；仍以实际资产包内许可证为准 |
| `qwen3-asr-1.7b` | Apache-2.0 | 目录层面可兼容；仍以实际资产包内许可证为准 |
| `kokoro-82m` | Apache-2.0 | 目录层面可兼容；仍以实际资产包内许可证为准 |
| `indextts-2.5` | Apache-2.0 | 目录层面可兼容；仍以实际资产包内许可证为准 |
| `cosyvoice2-0.5b` | Apache-2.0 | 目录层面可兼容；仍以实际资产包内许可证为准 |
| `paddleocr-vl-0.9b` | upstream-asset | `UNKNOWN`：必须读取实际资产包许可证后再发布 |
| `glm-ocr` | upstream-asset | `UNKNOWN`：必须读取实际资产包许可证后再发布 |

远端清单必须为每个模型声明许可证文件，且该文件必须包含在资产条目中。安装后许可证随模型保存在受管目录，设置页可查看。手动导入如果没有声明许可证，会明确显示“无许可证文件”；应用不会替用户推断授权。

当前仓库没有真实模型权重、平台 sidecar 二进制或它们的最终许可证归档，因此发布级许可证复核状态为 `NOT_EXECUTED`。

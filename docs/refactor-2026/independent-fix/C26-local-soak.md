# C26 本机资源循环证据

实际 Electron 源码壳中完成 6 次浏览器 start → navigate localhost 和 6 次有输出后取消任务，再逐个关闭浏览器。通过实际 Pi → mcp_call → browser → Electron 浏览器宿主执行；没有替换工具消费者，没有真实模型费用。每次工具的产品 Ask 审批经原 confirm API 完成，驱动器仅允许 start 和本次精确 localhost URL。此前另实际点击过 Ask「同意」。

运行命令与结构化结果在 `artifacts/refactor-2026/independent-fix/f05-soak/C26_RESULT.json`。主循环命令退出码 0，21 个进程树样本覆盖 7 个窗口（每窗口 3 次），首末样本相隔 **35.696 秒**。这是固定循环的短时间稳态证据，不应称为小时级压力运行。

浏览器实际 running 实例数依次为 1、2、3、4、5、5：第6次建立后，第1个实例已挂起，证实实际运行上限5；最终状态为空。6次取消都有不同当前 streamId，均收到真实 assistant_run_end status=aborted。最终进程数回到基线、RSS低于初始值；不能仅凭这些样本断言永不泄漏。未采集全部JS监听器数，缓存证据采用实际浏览器实例上限。F02同机产物验证可能影响机器调度，记录仅统计本壳后代。

原始 actions、events、resources、task-results JSONL 分别包含真实接口结果、事件、完整进程树及任务结果。第一次空会话 open 返回 no_browser_state，第一次自动审批因 reviewer unavailable 拒绝，第二次缺少 browser.start 的脚本错误均保留在子目录，没有将这些失败计入浏览器成功。

隔离修正：HOME 和 LINGXI_HOME 能隔离业务数据，但 macOS Electron userData 不随 HOME 改变。首轮使用末级 data，lsof 实证写入 `~/Library/Application Support/Data` 的 GPU/Dawn缓存，不能证明该目录全由本次创建，故未删除。发现后立即关闭本轮壳，改为随机唯一 basename；lsof 核实两次唯一缓存目录。最终全部被测 Electron 后代均退出（cleanup.json），两处确认属于本轮的唯一缓存目录已清理。没有触及真实 Hanako 数据；也不宣称首轮所有缓存写入完全隔离。

C25附加：同一实际会话持续输出45秒、90行中文期间，实际展开此前成功 browser.navigate 工具卡与调用参数，截图和AX在 tool-expand-streaming.*。这是持续输出期间工具详情操作证据，不覆盖长Markdown代码、真实中文IME合成。界面同时还显示已完成工具的待确认栏，原样保留截图，不将显示异常隐去。

最终 C26 的本机有界循环子项有证据；如原验收将“长运行”单独要求更长持续时间，则该子项仍未满足，不能把35.696秒扩大为长运行通过。

## 后续扩展验收（取代短循环结论）

主端要求后，另建随机唯一 userData，所有实时文件先写系统临时目录，结束后一次性归档到 `artifacts/refactor-2026/independent-fix/f05-soak-extended/`，未覆盖前述原始日志。

完成5批×6次真实 browser.start/navigate，共30次浏览器任务及30次收到输出后的取消，主循环297.370秒；随后3个恢复尾窗使观察超过5分钟。又复用最后同6个会话跑2批，新增12次浏览器任务+12次取消，用于区别新增会话积累。总计42次浏览器任务+42次取消、33窗口99个RSS/进程树样本，命令均退出0。

每批running实例1、2、3、4、5、5，关闭后0；首次5批打开进程均13、关闭均7。关闭后的稳态RSS依次1583024、1637168、1652912、1662336、1718352 KB，尾窗1719344 KB，未回落。GUI阶段关闭DevTools后另设复用段基线1436208 KB；同6会话两批关闭稳态1463504、1511408 KB，进程均6，仍增长约3.3%。两段因DevTools/界面加载不同不能直接作内存优化对比。未强制GC，不把总RSS等同JS堆，也不以固定采样数量证明无泄漏。

因此 **C26整体BLOCKED**：浏览器上限和进程回收有真实通过证据，但缓存保留与泄漏尚未区分；不改阈值或增加生产性能方案以制造通过。还需针对重复固定会话的内存保留做进一步定位。平台/真实供应商不在本机证据的外推范围。同机全量测试可能影响调度，测量只统计本壳后代。

# 本地模型子系统实施计划

## 目标

以用户 2026-09-02 附件为权威需求，在当前分支和工作区中由 Codex 独立完成并交付可验收的本地模型子系统；不覆盖现有改动，不提交、不推送、不建分支/工作树、不部署、不迁移真实数据。此前 ChatGPT Pro 结果只保留为历史审计输入，不作为实现来源或完成证据。

## 成功标准

- 统一的本地推理、生命周期、大模型单槽位、内存治理、资产下载、手动导入、后端探测和可观测契约落地。
- 本地嵌入、文字识别、语音转写、语音合成真正接入现有业务入口；云端路径和既有持久化语义不回归。
- 桌面设置、五语言、打包配置、脚本、文档与自动化测试完整。
- 本机可执行门禁真实通过；缺少真实模型资产、Windows/macOS Intel/NVIDIA 等外部环境的项目保持 `NOT_EXECUTED`，不得冒充通过。

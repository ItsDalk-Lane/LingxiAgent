## 已完成内容

### 统一运行与资源治理

- 建立八个稳定模型目录和稳定身份：`local:<id>@<quant>@<manifestVersion>`。
- 小模型支持进程内通道，大模型支持受控子进程通道；运行时工厂按清单选择，不按文件名猜测。
- 请求使用引用计数；首次调用冷加载，后续复用；空闲回收时间可热更新。
- 全局大模型只有一个槽位，后到请求排队，取消后不会继续加载。
- 加载前按声明内存、安全系数、当前占用和系统可用内存做预算；压力回收只处理无引用实例。
- 子进程只使用带随机令牌的标准输入输出协议，不开放监听端口；退出、超时和取消均有回收路径。
- 小模型预热是可取消、逐个执行的后台任务，单项失败不会拖垮应用。

### 资产与安装

- 远端清单严格校验版本、平台、精度、运行时、文件大小、逐文件 SHA-256、内存声明和许可证文件。
- 下载只接受 HTTPS，支持代理、镜像、断点、暂停、恢复、取消、速率和剩余时间。
- 下载完成逐文件校验；失败会重试一次，仍失败则显式报错并清理不可信残包。
- ZIP 解压拒绝路径逃逸、符号链接、大小写重名、未声明文件、高压缩比和大小超限。
- 手动导入支持有、无 `model.json` 两类目录。无元数据时先检查文件形态，再让用户选择模型与精度；准确运行契约只来自已验证清单，源目录不被写入。
- 模型许可证随受管安装保存，设置页可查看；缺少许可证时明确显示不可用。

### 四条业务链

- 本地嵌入接入知识摄入、知识查询和记忆检索，模型或精度变化会形成独立向量变体，不覆盖旧向量。
- 图片和无文字层 PDF 可走本地文字识别；普通文档继续使用原提取链。PDF 页面渲染有页数和像素上限。
- 本地语音识别接入桌面录音及 Bridge 入站音频；没有原始音频的平台不伪造离线转写。
- 本地语音合成接入助手消息朗读和 Bridge 语音回复。文字永远先送达，合成或上传失败显式保留文字。
- 朗读支持逐句排队、暂停、继续、停止、取消和音频资源释放。当前语义是“回复完成后由用户触发”，不是文字生成过程中的自动边生成边朗读。

### 桌面管理与配置

- 设置页按类别展示八个模型及安装、下载、暂停、恢复、取消、删除状态。
- 支持固定打开模型目录、拖拽/选择导入、无元数据二步确认、后端探测、线程、内存映射、锁页、大小模型空闲时间、预热、镜像和代理配置。
- 展示内存预留、唯一大模型槽位、真实运行后端、被拒绝目录和向量保留说明。
- 删除有二次确认；删除模型不顺手删除历史向量。
- 简体中文、繁体中文、英语、日语、韩语文案已补齐。

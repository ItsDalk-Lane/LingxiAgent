## 修改内容与防回归

1. llama 运行适配恢复自动省内存注意力计算，关闭默认高达 8 GiB 的跨请求提示缓存；同一活动槽位的短期前缀复用仍可能存在，重复同图热调用不能当新图速度。
2. 扫描 PDF 渲染后只裁掉外围完全纯白区域，任何非白像素、浅色字符和页边标记都保留，留 16 像素边距；不缩放字号，不按灰度阈值丢字。扫描循环每 64 行让出执行时间，并检查取消。
3. 识别按不超过 8 秒且优先低能量停顿处分段，不丢采样点、不重叠重复输入；每段前后检查取消。朗读优先标点、最多 12 个字符分段，分段拼接严格等于原文，段间检查取消。
4. 原生推理已取消但返回普通错误时，统一标记为取消；等待原生结束后才释放引用，禁止只让调用方提前返回。
5. 关闭语音原生工作内存池和内存模式缓存，减少长输入留下的高水位；不加入无效的强制垃圾回收或系统分配器探针作为产品依赖。

注意：短分段可能影响长句语调和跨段识别上下文，多语言质量仍需扩展测试集；当前不宣称朗读声音质量与流式播放目标全部满足。普通图片路径保持原输入不裁切，只有 PDF 渲染页做纯白边缘处理。

## 仍需确认的边界

原任务明确要求两项小语音模型在应用进程内部运行。当前包装依赖原生终结器，实测关闭内存池、主动垃圾回收、系统压力释放均不能保证每次卸载后驻留内存下降 95%，朗读还存在实际物理保留。因此不能仅凭“实例已清空”宣布修复。

建议改为受控独立进程：卸载或超时取消时等待进程退出，由操作系统回收全部模型地址空间；仍保持按需启动、闲时退出、不占大模型槽位、仅本机通信、不要求用户安装外部运行时。它会改变原任务的“进程内”硬要求，**已向用户询问，尚未获得确认，未实施该变更**。新模式的延迟和完整退出仍需实施后实测，不能提前标通过。

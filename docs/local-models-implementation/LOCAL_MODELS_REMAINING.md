## Phase 6 历史优先事项

四类真实模型已下载、校验、导入并离线运行，不能再把所有本机工作归因于“缺资产”。当前实测见 [本机真实验证报告](LOCAL_MODELS_REAL_VALIDATION_REPORT.md)。先处理：

1. 语音模型卸载后物理内存不回落；合成长句取消超过 1 秒，识别在竞争负载下也超过 1 秒。
2. 纯 CPU 识字新扫描页约 110.5 秒，进程树峰值约 9.1 GiB；完成时单点内存不能冒充峰值。
3. 剩余模型及精度需要真实适配和测试；本轮仅四类各一个模型，不是全部模型清单通过。
4. 桌面录音格式、分段检测、上屏、朗读交互及真实 Bridge 端到端仍未验证；当前原生语音识别只支持 WAV，合成输出完整音频，不是真正音频分片流。
5. 手动导入 UI、应用内下载跨重启恢复、镜像/代理、删除、模型观测页及默认内存预算仍需实机验收。
6. 许可证/正式分发、多平台和正式发布仍保留；SenseVoice 是自定义模型许可，GLM 权重声明和代码 LICENSE 必须区分。

## 建议执行顺序

1. 先做资产和许可证审计，任何摘要、运行参数或许可证不确定都不要发布。
2. 先选 darwin-arm64 的两个 small 模型做最小真实闭环，完成下载、导入、离线推理、取消、TTL 和内存观测。
3. 再接一个 large sidecar，验证单槽位、排队、崩溃恢复和退出清理。
4. 完成 macOS Intel、Windows、Linux 原生归档和安装包 smoke；每个平台只携带自己的二进制。
5. 按 `docs/LOCAL_MODELS_E2E_CHECKLIST.md` 跑四条业务链和断网场景。
6. 用 `npm run benchmark:local-models` 在下限机和主流机记录冷加载、热调用、峰值内存、实时率与首音延迟。
7. 最后执行正式签名、公证、Release、更新链和发布许可证复核；这些操作需要单独授权。

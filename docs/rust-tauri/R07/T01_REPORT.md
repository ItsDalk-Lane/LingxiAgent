## 时间与回收规则

每分钟检查，单批顺序执行；同批检查忙时让路，不移动待执行游标。错过多个时点只补一次；间隔从真实完成时间重算，最短一分钟。HTTP 管理入口保留“字符串为分钟、数字为毫秒”，内部和数据库为毫秒。

cron 使用服务机器本地日历，搜索游标沿 UTC 向前：夏令时缺失时刻跳过；回拨产生的两个实际时点分别最多一次。运行中系统时钟回拨时，下一游标不退过已经领取的到期时间。重启已完成但未结算的 Run，按真实终态时间和冻结计划恢复，能够补一次漏跑。

一次性任务执行后关闭；失败保留既有退避。超时、停止或撤权均请求原 Run 取消并等待真实清理；无法确认时记 Unknown。两个宿主的清理等待可被外层超时打断，未退出句柄仍留在宿主；重复或并发等待不会提前报告完成。

心跳保持总开关、助手明确启用、默认 31 分钟、Unix 时间槽及手动两分钟冷却。巡检与笺使用现有 ResourceIO 和固定日志工具；成功写回后才更新材料指纹。每日整理沿真实 Bridge 名册和现有 fresh-compact，不重复启动记忆/梦境处理；忙碌剩余目标一小时后重查。

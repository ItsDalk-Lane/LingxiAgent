## 读法与共同关闭条件

| 记号 | 含义 |
|---|---|
| 原生 | 首轮实现已有的缺陷；“后修引入”指某次修复改变了行为；“同根漏修”指旧修未覆盖相邻入口；“证据不足”指不能凭缺失材料认定产品新坏。 |
| 静 / 实 | “静”是旧评审或本轮源码推断；“实”是**旧候选**真实观察，绝非本候选已复现。原始来源是对应的 `/tmp/r02-stage-review-rN.md` 与 [哈希索引](../../../artifacts/rust-tauri/R02/audit-r16/history-stage-report-sha256.txt)。 |
| 静态修正 / OPEN / BLOCKED | 静态修正仍待同根入口和失败分支真验；OPEN 表示代码或证据仍有缺口；BLOCKED 表示必需检查目前无获准执行的完整结果。任何一项不等于阶段 PASS。 |
